# All Aboard Contractors website

- Live site: https://allaboardcontractors.com
- Editor: https://allaboardcontractors.com/admin (log in with your invite email)

Site text, photos and contact details live in `content/` and are edited through the editor.
Netlify runs `node build.js` on every change, which fills `src/template.html` with that content and publishes `dist/`.
